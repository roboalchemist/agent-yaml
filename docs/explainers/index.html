agent-yaml

Docs

Guides for writing a workflow, running it under any agent CLI, and proving that each step did its job.

Start here

pip install "git+https://github.com/roboalchemist/agent-yaml.git"
mkdir -p /tmp/hello
# hello.yaml
directory: /tmp/hello
cli-agent: opencode
task:
  - write-file:
      prompt: "Create hello.txt containing: hello from agent-yaml"
agent-yaml validate hello.yaml        # parse and schema check
agent-yaml run hello.yaml --dry-run   # print the exact command
agent-yaml run hello.yaml             # call the agent

Reading order

For a first workflow, this order avoids the usual dead ends.

  1. Primitives. Know the field names before writing any YAML.
  2. Task tree. Decide what runs in order and what can run together.
  3. Authoring. Write the file, then run agent-yaml validate.
  4. Validators. Add a check per task that writes an artifact, then run with --dry-run before spending tokens.
  5. Loops. Add a loop only once the single-item case works.

The HTML pages are self-contained and open from disk. The Markdown guides render on GitHub and in the MkDocs site.
