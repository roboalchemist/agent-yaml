# Agent YAML Visual Runner Mock Prompts

These prompts are for `$imagegen` when the image tool is available. They should
produce quick UI direction mocks before committing to a final CSS theme.

Shared constraints for every prompt:

- Use case: `ui-mockup`
- Asset type: desktop web app product mockup
- Primary request: n8n-style and ComfyUI-style visual workflow editor for running scheduled `agent-yaml` automations
- Required UI: left workflow/schedule sidebar, central plug-and-play node canvas, right node inspector, bottom run timeline/log drawer, top run/dry-run controls
- Text must be minimal and legible: `agent-yaml`, `Run`, `Dry Run`, `Schedule`, `Task`, `Loop`, `Router`, `Validator`, `Running`, `Succeeded`, `Failed`
- Avoid: fake brand logos, unreadable microtext, mobile layout, generic SaaS purple-white theme

## Graphite Console

Dark graphite developer-console interface, phosphor green accents, terminal-like
status lights, thick rounded ComfyUI nodes, animated edge paths implied with glow,
serious infrastructure tool aesthetic.

## Blueprint Paper

Cream blueprint drafting surface, navy ink nodes, construction-line grid,
technical annotations, warm orange active-run indicators, like an automation
diagram pinned to an engineering desk.

## Terminal Mission Control

High-density operations dashboard, black glass panels, cyan and amber status
telemetry, timeline drawer with event rows, route nodes shown as switchboards,
industrial monitoring feel.

## Warm Industrial

Charcoal and oxidized brass palette, tactile cards, chunky ports, subtle noise
texture, scheduler controls that feel like hardware toggles, polished but not
corporate.

## Comfy Lab

Direct ComfyUI-inspired node lab, dark canvas, vivid typed sockets, compact node
headers, colored edge noodles, inspector showing YAML fields, run states painted
onto each node.

## Dataflow Garden

Organic graph layout with moss green, clay, and pale sky accents, flowing edge
paths, schedule nodes as seed pods, runtime states as glowing growth rings,
friendly but still technical.
